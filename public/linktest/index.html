Phone ↔ tablet link test

Checks that the scorer's phone and the table tablet keep talking with no internet, over the phone's hotspot.

Before you start (both devices)
  1. Open this page once on each device with internet, so it works offline later.
  2. iPhone: Settings → Personal Hotspot on. Keep mobile data on (no signal is fine).
  3. Tablet: Wi-Fi → join the iPhone's hotspot. If it says "no internet", choose Stay connected.
  4. To test with no internet: iPhone Settings → Mobile Data → turn it off for Safari only, or go where there's no signal.
